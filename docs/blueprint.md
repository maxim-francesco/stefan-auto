# **App Name**: Global Greeter

## Core Features:

- Language Selection: Users can select a language from a dropdown menu.
- Localized Greeting: Display a 'Hello World' message in the selected language.
- Language Data: Maintain a data structure of supported languages and their 'Hello World' translations.

## Style Guidelines:

- Primary color: Light sky blue (#87CEEB) for a friendly and approachable feel.
- Background color: Very light cyan (#E0FFFF) to keep it clean and airy.
- Accent color: Soft yellow (#F0E68C) for interactive elements.
- Body and headline font: 'PT Sans' for a modern, readable interface.
- Simple, centered layout with the language selection at the top and the greeting displayed prominently below.
- Fade-in animation for the greeting text when the language is changed.
